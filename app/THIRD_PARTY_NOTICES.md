# Third-party assets

## WoodenFish

`assets/vendor/wooden-fish/WoodenFish.svg` is copied without modification from
[Ares-Chang/wooden-fish](https://github.com/Ares-Chang/wooden-fish),
commit `e50c0477224f7f0b9e2b3752df60d940efebdeab`,
source path `src/assets/WoodenFish.svg`.

Copyright (c) 2022-PRESENT Chang. MIT License.
The complete license is included at `assets/vendor/wooden-fish/LICENSE`.

XWalnut displays the original SVG image with a CSS color filter in its existing tool
window. Only its presentation color and size are adapted. The asset is bundled
locally and does not require a network connection.

## Lucide

The numeric keypad's inline delete/backspace SVG uses the
[Lucide delete icon](https://lucide.dev/icons/delete), from
`lucide-icons/lucide` commit `94e4cb9d9db5907053ebf3636a97c45529cf776b`
(`icons/delete.svg`). The paths are unchanged; stroke width and size follow
XWalnut's controls. Existing player icons also use Lucide paths.

The complete upstream license, including the Feather attribution for derived
icons, is included at `assets/vendor/lucide/LICENSE`.
